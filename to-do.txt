--- STORY OBJECT ---
Behandles som et object, men kan aktiveres på maps, hvor det er på med E 
E udløser en modal med tekst på - denne tekst kan være historie eller hjælpe hint 
Story object kan også være et para i region som peger på et object det altid spawner på det givne map 
Hvis story para fylder for meget, laver vi story config fil 
måske bare object skal kunne få en para (objectType: normal (default), quest (kun hvis relaterede quest er tilgængelig), story (e prompt))
normal = default som det er nu
quest = kan spawne 1 entry, hvis relaterede quest betingelse er opfyldt (bruger også questens spawnrate)
story = kan spawne 1 entry på map

Måske det er region der skal have mulighed for at gøre object til quest objekt eller story object i stedet for selve object listen. Ved quest eller story, er det en random af de mulige 16 objects der bruges, medmindre x og y er sat. - hvor skal story stå? Måske story skal være config fil for sig selv, som så kan kaldes med variable/id - til alt, der bruger story.
